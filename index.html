📑 Atendimento aos 4 Requisitos Oficiais do Trabalho

Padrão WCAG AAA & SUS

1. Componentização & Microserviços

• Estrutura modular desacoplada em componentes semânticos (Header, Viewport, Sheets, Cards, Calendário).
• Camada de microserviços simulada via scripts/mock-services.js (AuthService, AppointmentService, DoctorService, NotificationService), garantindo resiliência se um serviço falhar.

2. Design System no Código & Bootstrap 5.3

• Integração oficial do framework Bootstrap 5.3 com customização interna de tokens (--bs-primary, --bs-body-bg).
• Paleta 60-30-10 e botão dinâmico de Modo Sênior (+20% de fonte e contraste ampliado).

3. Protótipo Funcional Responsivo (Framework Moderno)

• Uso do Bootstrap 5.3 como framework de estilização de mercado obrigatório.
• 100% responsivo (Mobile-First) e funcional sem banco de dados com persistência via LocalStorage.

4. Acessibilidade Prática (WCAG 2.1 AAA)

• Semântica: <header>, <nav>, <main>, <section>, <fieldset>, <legend>.
• ARIA & Alt: aria-label em botões de ícone, aria-pressed no Modo Sênior, aria-live="polite" para alertas e aria-hidden="true" em ícones decorativos.
• Teclado: Navegação total por Tab, anel de foco visível de 3px e tecla Esc para fechar modais.
